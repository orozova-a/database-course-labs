# Book Reading Tracker - Final Project

# Description
This project is a PostgreSQL database system designed to track book reading progress, quotes, reviews, and personal libraries.

## Features
- Users and profiles
- Books, authors, and genres
- Reading progress tracking
- Quotes with emotions and highlight colors
- Personal bookshelves
- Reviews and ratings
- Transactions and rollback demo
- Indexes for optimization
- Backup and restore support

## Technologies
- PostgreSQL
- pgAdmin
- SQL

## Files
File | Description
book_tracker_backup.sql | Full database backup 
schema.sql | Table creation - database structure
queries.sql | SQL queries
data.sql | Sample Data

## How to Restore
1. Open pgAdmin
2. Create empty database
3. Right-click → Restore
4. Choose `book_tracker_backup.sql`
5. Done
